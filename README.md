
# Fullstack WebApp Simulation

A simple website that simulates fullstack interaction between front and back-end.

## Features

- Create/Register account
- Login into account
## Deployment

To deploy this project run

```bash
  npm install
```


## Environment Variables

CI = false because vercel doesn't allow vulnerabilities on deploy

`CI` 



## Run Locally

Clone the project

```bash
  git clone https://github.com/brunobgsilva/react-template-client
```

Go to the project directory

```bash
  cd react-template-client
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run start
```
